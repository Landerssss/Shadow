## 六、关键结算规则

| 规则        | 内容                                                            |
| --------- | ------------------------------------------------------------- |
| 玩家普通减伤    | `伤害 × (1 - 防御倍率 × 0.9)`，最低 1 点                                |
| 防御收益      | 每 1% 面板防御实际提供 0.9% 减伤                                         |
| 真实伤害      | BOSS 撞击 44%、锁链 33%，无视防御与无敌；不被蚀影护壳拦截                           |
| 敌人减伤      | 玩家 10 级后普通怪 20%；BOSS 不参与该减伤                                   |
| 敌人伤害成长    | 每 60 秒 ×1.225，与生命同步                                           |
| 暴击        | 因果残响 / 不灭的暗影（玩家子弹）、不息的暗影（弹球直接碰撞）基础 15% 概率、1.5 倍伤害；「暗影洞察」可继续提高暴击率；暴击不重复掉落余烬 |
| 蚀影护壳吸收    | 普通可减免伤害先经防御计算，再由护壳吸收，剩余扣除生命；声波怪强制扣血绕过护壳                       |
| 恢复转化      | 所有友方恢复经 `Player.heal` 统一入口：实际恢复×比例 + 溢出恢复×100% 转护壳（盛宴 +25%）   |
| 基础汲取      | 玩家直接攻击按有效攻击批次限频（每批 1 次、每秒 ≤4 次）；主冲击/壳裂/回潮/裂光不触发汲取             |
| 蚀白冲击结算    | 伤害只在指定结算时刻造成一次，不按动画帧重复；同帧不递归连发，下一次需等待正常冷却与下一次更新               |
| 遗蜕唯一性     | 每敌一次死亡掉落、每余烬/遗蜕收集一次、每遗蜕引爆一次；壳裂不引爆其他遗蜕                         |
| BOSS 共享血池 | 每个伤害源（主冲击/壳裂/回潮/裂光/脐带脉冲）对 BOSS 群只结算一次                         |
| 穿透        | 「暗影贯穿」后子弹穿透 1 个敌人，穿透命中伤害 ×0.65                                |
| 散弹        | 三发独立结算，每发均为完整伤害                                               |
| 吸血        | 击杀时按有效最大生命百分比回复                                               |
| 暗影君王      | 击杀后直接增加基础伤害，可被伤害倍率放大                                          |
| 连线伤害      | 每对「暗影实体—敌人」终身只触发一次                                            |
| 因果反应伤害    | 同目标同反应 400 ms 冷却；BOSS 承受因果反应伤害 ×0.5                           |
| 白蚀爆裂      | 3 标签触发后节点消耗；反应事件不生成完整节点、不伪造 KILL/DEATH                        |
| 弹射直接碰撞    | 伤害 = 玩家有效攻击（蓄能首发 ×1.2、雷霆球 ×1.2），可暴击；同球同敌 250 ms（按攻速缩短，最低 120 ms）、BOSS 共享血池 250 ms；计入冰封有效命中与导电/过载计数 |
| 弹射派生伤害    | 电弧 / 雷霆爆炸 / 磁场与电磁场 tick 不暴击、不计冰封、不递归、不触发碰撞反弹；BOSS 共享血池同次 / 同 tick 只结算一次                    |
| 弹球安全回收    | 弹球离玩家超过 2 倍回弹边界 → 瞬移回玩家附近，0.15 秒内不造成伤害、不消费过载/导电次数；边界位置校正不计伤害           |
| 磁极激活      | 同球同节点 600 ms 限频、每枚 2 次激活；残核本身不造成伤害，只提供反弹 / 加速（+20%，1.5 秒）/ 导电             |
