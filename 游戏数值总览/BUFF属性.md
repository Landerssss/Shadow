## 四、通用强化卡（BUFF）

### 4.1 可重复选择的属性卡

> 数值按“该卡已选次数”分档：第 1 次 5~~10%，第 2 次 10~~20%，第 3 次及以后 20~30%。每次选择独立随机。

| 卡名   | 简称      | 效果                                            | 数值区间                                            |
| ---- | ------- | --------------------------------------------- | ----------------------------------------------- |
| 暗影躯体 | 躯体 / 血量 | 最大生命提高                                        | 5~~10% → 10~~20% → 20~30%                       |
| 暗影力量 | 力量 / 伤害 | 玩家伤害提高                                        | 5~~10% → 10~~20% → 20~30%                       |
| 暗影疾行 | 疾行 / 攻速 | 攻击速度提高                                        | 5~~10% → 10~~20% → 20~30%                       |
| 暗影护盾 | 护盾 / 防御 | 受到伤害减少                                        | **3~8%**（4 级解锁，实际减伤 ×0.9）                       |
| 暗影汲取 | 汲取 / 吸血 | 击杀回复最大生命                                      | **3~8%**（4 级解锁）                                 |
| 暗影疾步 | 疾步 / 移速 | 移动速度提高                                        | **5~10%**                                       |
| 暗影洞察 | 洞察 / 暴击 | 因果残响 / 不灭的暗影：暴击率提高（强化原攻击，暴击不重复掉落余烬）；不息的暗影：暴击率提高（弹球直接碰撞判定一次，派生伤害不重复暴击）；其他流派：伤害提高 | 因果残响 / 不灭的暗影 / 不息的暗影 **3~8%** 暴击率；其他 **2~5%** 伤害（4 级解锁） |

| ---- | -- | --------------------------- | --------------------------------- |

| 暗影连线 | 连线 | 玩家与每个暗影实体之间生成连线，敌人穿过受到伤害    | **20 伤害**；同一连线对同一敌人仅一次            |
| 暗影散弹 | 散弹 | 攻击变为三方向                     | 左右各 **±30°**                      |

| 暗影能源 | 能源 | 每隔 5 秒回复最大生命                | **15% / 5 秒**                     |

| 暗影领域 | 领域 | 技能范围提高（白蚀爆裂、冰裂、公共爆炸半径增大）    | **+12%**                          |
| 暗影律动 | 律动 | 公共机制冷却缩减（公闪更频繁、因果节点延迟更短）    | **-12%**                          |

**公共机制在流派四（因果残响）的适配**

| 机制卡  | 流派四表现                                                              |
| ---- | -------------------------------------------------------------------- |
| 死亡暗影 | 生成**死亡回响节点**（4 秒），而非暗影实体/小漩涡                                         |
| 暗影冰封 | 冰封时在目标位置生成**冰封因果节点**：后续事件触发冰裂                                        |
| 公共爆炸 | **【已隐藏】** 爆炸生成**爆裂节点**（命中计数：≥1 输入 HIT、≥3 输入 RUPTURE）                 |
| 公共闪电 | 落雷位置留下**闪电节点**，冷却受暗影律动缩减                                             |
| 暗影连线 | 流派四内由因果节点互连产生**因果连线**（≤3 个节点、300 px 内），敌人穿过 20 伤害；3 节点闭合成三角时触发白蚀爆裂 |

**公共机制在流派五（不息的暗影 / 弹射流）的适配**

| 机制卡   | 流派五表现                                                              |
| ----- | -------------------------------------------------------------------- |
| 死亡暗影  | 生成**磁极残核**（4 秒、上限 8、每枚 2 次激活），残核本身不造成伤害：普通球获得导电 + 加速 + 短电弧       |
| 暗影连线  | 玩家 ↔ 最近 **3 个**有效弹球连线（召回/蓄能/瞄准中的球不参与），敌人穿过 20 伤害（同球同敌 1 秒限频）；不复制弹球、不触发碰撞/导电/反弹 |
| 暗影散弹  | 弹球上限 **+2**（不复制现有弹球）                                                 |
| 暗影贯穿  | 直接碰撞段穿透：第 1 敌正常伤害不反弹，第 2 敌 ×0.65 后反弹                                   |
| 暗影领域  | 电弧 / 磁场 / 电磁场 / 雷霆爆炸 / 磁极接触半径受范围加成；回弹边界与弹球半径不变                          |
| 暗影律动  | 落雷冷却缩减；蓄能周期同步缩短（最多至基础值 75%）                                            |
| 公共闪电  | 落雷冷却受「暗影律动」缩减；雷区麻痹与弹球麻痹独立计算                                            |

### 4.3 卡牌出现规则

| 条件         | 规则                                                            |
| ---------- | ------------------------------------------------------------- |
| 升级选卡       | 10 级前 3 张，10 级后 4 张                                           |
| 必定出现（顺序随机） | 当前流派下一级专属卡（未满级时必定出现）；从未选择过的一次性机制卡中随机 1 张（必定出现）。两类卡在卡池中的展示顺序随机 |
| 其余         | 通用属性卡中随机补足，不重复                                                |
| 解锁限制       | 护盾、汲取、洞察需要玩家达到 4 级才会进入卡池                                      |
| 隐藏卡        | 公共爆炸暂时隐藏，不进入卡池（代码保留，重新启用只需去掉 `hidden` 标记）                     |
| 无尽模式       | 所有 BUFF 数值加成 **×5**（一次性机制卡不受影响）                               |
