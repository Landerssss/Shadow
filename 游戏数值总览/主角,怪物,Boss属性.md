### 1.2 升级成长

| 项目   | 每级变化                | 备注                     |
| ---- | ------------------- | ---------------------- |
| 伤害   | **+1.5**            | 直接加在基础伤害上              |

### 1.3 玩家伤害公式

| 场景     | 公式                                       |
| ------ | ---------------------------------------- |
| 有效伤害   | `基础伤害 × 伤害倍率(dmgMult)`                   |
| 有效攻速   | `基础攻速 × 攻速倍率(aspdMult)`                  |
| 有效最大生命 | `最大生命 × 生命倍率(hpMult)`，四舍五入               |
| 受到普通伤害 | `max(1, 伤害 × (1 - 防御倍率 × 0.9 - 因果残响守护))` |
| 受到真实伤害 | 原值，无视防御与无敌（BOSS 撞击 / 锁链）                 |
| 击杀回复   | `有效最大生命 × 吸血比例`                          |

### 2.5 三种新普通敌人机制

**裂角突袭者（`charger`）——迫使玩家横向躲避**

| 阶段  | 数值 / 规则                                                        |
| --- | -------------------------------------------------------------- |
| 追击  | 110 px/s 追向玩家；接触伤害 8 点                                        |
| 触发  | 玩家进入 **260px** 且冲锋冷却完成 → 蓄势；首次生成后至少等 **1 秒**               |
| 蓄势  | **0.65 秒**：停止移动，开始即锁定方向（结束不重新瞄准）；身体压低、裂角变亮、地面狭长暗红通道 + 前端三角箭头（不造成伤害） |
| 冲锋  | **360 px/s**，持续 **0.5 秒**，最大 **180px**；直线不转弯；撞地图边界/不可穿越障碍提前结束（普通敌人不算墙） |
| 命中  | 冲锋命中 **14** 点普通伤害，一次冲锋最多成功命中 **1 次**；不叠加 8 点接触伤害；走玩家受伤入口（吃无敌帧/防御/护壳） |
| 恢复  | **0.55 秒**暂停追击，随后回到正常追击                                      |
| 冷却  | **4.5 秒**，从冲锋结束开始计算                                            |
| 控制  | 减速（含暗影冰封）通过统一移速倍率同时影响追击与冲锋；麻痹可中断蓄势/冲锋；不自带控制免疫          |
| 路径  | 冲锋按移动路径做碰撞检测（低帧率/玩家高速移动不会被穿过），路径命中与接触伤害不重复结算             |

**重甲守卫（`bulwark`）——增加敌群耐久、打乱处理优先级**

- 55 px/s 缓慢追击，接触伤害 16 点；没有远程、没有冲锋、不嘲讽、不反弹子弹、不给周围敌人减伤。
- 自身减伤 **10%**，与 10 级后普通怪 **20%** 减伤乘算：最终伤害 = 基础 ×0.9×0.8（例：25 ×0.9×0.8 = 18）。
- 生命强化单独计算：180 × 时间生命倍率 × 10 级生命强化倍率。
- 正常受冰封/减速/麻痹/漩涡吸引，无隐藏抗性。
- 外观：暗红黑六边形宽厚甲壳、正面厚甲分块、中央窄红眼、短粗足爪、移动缓慢摆动；受击甲片局部闪红；低血量显示甲壳裂纹（仅视觉）。

**灰烬投手（`lobber`）——迫使玩家离开当前位置**

| 阶段 | 数值 / 规则                                                                |
| -- | ---------------------------------------------------------------------- |
| 移动 | 距离 >400px 缓慢靠近；进入 400px 后停下投掷；最大攻击距离 480px（不绕路、不风筝、不后退）            |
| 触发 | 首次生成后至少等 **1.5 秒** 才能攻击                                                   |
| 抬手 | **0.3 秒**：举起灰烬囊、囊体收缩发亮（攻击前摇）                                            |
| 投掷 | 投掷瞬间锁定玩家当前位置为**固定世界坐标**，同时显示落点预警；飞行中不追踪、不修正落点                        |
| 飞行 | **0.9 秒**明显抛物线；炸弹暗红外壳 + 橙色裂缝；高度偏移只影响绘制，不改变爆炸坐标；炸弹不可被攻击、不被子弹/弹球误判为敌人 |
| 预警 | 从投掷时开始持续 0.9 秒：爆炸半径 **65px** 暗红半透明地面 + 橙红外圈 + 中心尖齿/三角标记，边缘逐渐收拢，不闪烁 |
| 爆炸 | 范围内玩家一次性 **14** 点普通伤害；走玩家受伤入口（吃无敌帧/防御/护壳）；不逐帧重复、不伤敌人、不留持续伤害区、不加燃烧 |
| 冷却 | **3.8 秒**，从投掷完成后开始计算；不随时间无限缩短                                           |
| 死亡 | 已抛出的炸弹继续按原落点结算；未完成的抬手取消；死亡/通关/重开统一清理所有未结算炸弹                        |

> 视觉区分：三种新怪共享敌方识别特征（黑/暗红实体轮廓、红眼、尖角/爪/甲片、暗红橙红敌方预警）；冲锋拖尾是暗红碎线（不是弹球完整光尾），落点预警不使用引雷蓝白地面圈、也不使用因果节点紫青圆环。
