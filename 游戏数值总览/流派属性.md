### 3.4 流派三：不灭的暗影（Shadow Undying / 不灭 / 护壳 / 汲取）

**核心对象：蚀影护壳**（附着于玩家的独立资源，不是分身、漩涡或因果节点）

**基础机制（Lv.1）**

| 项目     |                           数值 | 说明                                        |
| ------ | ---------------------------: | ----------------------------------------- |
| 护壳容量   |                 最大生命 **30%** | 独立于生命值存储；Lv.3 提升至 45%                     |
| 恢复转化   | 实际恢复 **50%** + 溢出恢复 **100%** | 通过 `Player.heal` 统一恢复入口结算；Lv.3 实际恢复提至 75% |
| 基础汲取   |       每有效攻击批次恢复最大生命 **0.5%** | 一次开火（含散弹）= 一批次；每秒最多 **4 次**               |
| 死亡余烬   |     存在 **5 秒**，恢复最大生命 **1%** | 击杀掉落；100 px 内自动收集（Lv.2 范围 +40%）           |
| 余烬遗蜕   |     存在 **4 秒**，恢复最大生命 **2%** | 死亡阴影在本流派的形态，替代同击杀普通余烬                     |
| 蚀白冲击冷却 |                    **1.2 秒** | 自动触发，无需操作                                 |
| 蚀白冲击阈值 |                护壳达容量 **30%** | 触发时消耗当前护壳 **20%**                         |
| 冲击半径   |                   **240 px** | 受技能范围加成                                   |
| 冲击伤害   |    `玩家攻击 × 1.6 + 实际消耗护壳 × 2` | 加成只应用一次                                   |

**逐级强化**

| 等级   | 卡名   | 简称 | 具体数值 / 机制                                                                                            |
| ---- | ---- | -- | ---------------------------------------------------------------------------------------------------- |
| Lv.1 | 初始形态 | 不灭 | 护壳 + 汲取 + 余烬 + 蚀白冲击即刻可用                                                                              |
| Lv.2 | 饥渴余烬 | 饥渴 | 自动收集范围 **+40%**（100 → 140 px）；余烬/遗蜕恢复量 **+25%**（1% → 1.25%，2% → 2.5%）                                |
| Lv.3 | 蚀影增殖 | 增殖 | 护壳容量 30% → **45%** 最大生命；实际恢复转护壳 50% → **75%**                                                        |
| Lv.4 | 裂壳回潮 | 回潮 | 主冲击命中后 **0.35 秒**产生收缩回潮：伤害 = 主冲击 **35%**，向玩家方向收集范围内余烬；不耗护壳、不产生下一道回潮                                  |
| Lv.5 | 临界喂养 | 蓄势 | 主冲击进入 **0.18 秒**蓄势：蓄势期新增护壳的 50% 计入额外消耗（上限最大护壳 **20%**），额外消耗提高冲击伤害，半径最多 **+25%**；玩家死亡取消未结算攻击          |

| Lv.7 | 不灭盛宴 | 盛宴 | 一次主冲击及余波收集 **≥3 份**余烬资源 → 进入盛宴 **4 秒**：恢复转护壳 **+25%**，主冲击额外释放 **4 道**尖瓣裂光（各 **25%** 主冲击伤害）；刷新持续时间不叠乘 |

**公共机制适配**

| 机制卡      | 流派三表现                                                                                 |
| -------- | ------------------------------------------------------------------------------------- |
| 死亡阴影     | 生成**余烬遗蜕**（4 秒倒伏空壳），不生成分身/漩涡/因果节点；替代该次击杀的普通死亡余烬                                       |

| 暗影能源     | 每 5 秒 15% 恢复经统一入口结算，实际恢复 + 全部溢出转护壳（满血依然生效）                                            |
| 暗影洞察     | 暴击率提高，强化原攻击；暴击不重复掉落余烬                                                                 |
| 死亡余烬掉率   | 主冲击/壳裂/回潮/尖瓣裂光造成的真实击杀均可正常生成余烬或遗蜕                                                      |
